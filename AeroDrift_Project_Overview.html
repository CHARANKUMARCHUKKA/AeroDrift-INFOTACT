AeroDrift: Project Overview & User Guide

Part 1: What is AeroDrift? (In Simple Words)

The Problem: Imagine a company has hundreds of servers running in the cloud (AWS, Google Cloud, Azure). These servers are protected by "virtual doors" (firewalls). Sometimes, an engineer might temporarily "unlock a door" to fix a bug, but then they forget to lock it back. This is called "Infrastructure Drift." If a hacker finds that unlocked door, the company gets breached.

The Solution: AeroDrift is like an automated, 24/7 robotic security guard for the cloud.

  • It Maps the Building: It constantly connects to AWS, Azure, and Google Cloud to draw a map of every single server and firewall the company owns.
  • It Checks the Doors: It runs security scans in the background to see if any doors (ports) were accidentally left unlocked to the public internet.
  • It Sounds the Alarm: If it finds a vulnerability, it instantly alerts the security team on a beautiful web dashboard, sends an email, and posts a message to Slack/Microsoft Teams.
  • It Locks the Door (Remediation): If authorized, it can actually write code to automatically lock the door back up, fixing the problem before a hacker can get in.

In technical terms: AeroDrift is a Multi-Cloud DevSecOps platform built with a Python FastAPI backend and a Streamlit frontend, fully containerized with Docker, Kubernetes, and Terraform infrastructure-as-code.

Part 2: Why Use AeroDrift? (Business Value)

In today's fast-moving tech environment, companies deploy code hundreds of times a day across multiple cloud providers. This creates massive security risks:

  • Preventing Costly Data Breaches: A single misconfigured database or open firewall port can lead to millions of dollars in fines (like GDPR or HIPAA violations) and lost customer trust. AeroDrift catches these human errors before hackers do.
  • Eliminating "Shadow IT": Developers sometimes spin up servers for quick tests and forget to shut them down or secure them. AeroDrift automatically discovers every hidden asset in the cloud.
  • Saving Security Teams Hundreds of Hours: Without AeroDrift, security engineers have to manually log into AWS, Azure, and Google Cloud, clicking through hundreds of menus to check firewall rules. AeroDrift automates this entirely, freeing up the team to focus on higher-level threats.
  • Instant SOC2 Compliance: Government and enterprise contracts require strict compliance audits (like SOC2). AeroDrift's one-click CSV export provides instant mathematical proof to auditors that the environment is secure and monitored 24/7.

Part 3: How to Use the Application

Here is a step-by-step guide on how a Cybersecurity Engineer uses the AeroDrift platform to secure their company:

Step 1: Secure Login

The engineer opens the AeroDrift dashboard in their web browser. Because the system is protected by Enterprise JWT (JSON Web Token) Security and Role-Based Access Control, they must log in using their secure administrator credentials.

Step 2: Understand the Architecture (Topology Tab)

They click on the Topology tab. Here, they see a visual list of all the company's servers, databases, and networks across AWS, Azure, and Google Cloud. This allows the engineer to know exactly what infrastructure exists in their environment at any given second.

Step 3: Run a Security Sweep (Drift Alerts Tab)

They navigate to the Drift Alerts tab and click the "Run Security Scan" button. AeroDrift pushes this task to a background thread (so the web page doesn't freeze) and quietly checks hundreds of servers to see if anyone accidentally left a firewall open (like port 22 or 443).

Step 4: Fix the Vulnerabilities

If AeroDrift finds an exposed server, a red alert immediately pops up on the screen saying "CRITICAL: Subnet is public and exposed!" The engineer now knows exactly which server is in danger and can fix it before a hacker finds it.

Step 5: Export Compliance Proof (Audit History Tab)

At the end of the month, the engineer's boss (or a government compliance auditor) asks, "Is our cloud secure?" The engineer goes to the Audit History tab, clicks Download Compliance Report, and is instantly given an Excel spreadsheet (CSV) showing a permanent record of every scan they ran and every problem they fixed.
